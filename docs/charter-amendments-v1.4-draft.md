**案1【A1+G4 合并】闸门正身归位 + 治本落地判据**
- A1 原文：charter 新增"闸门"节为正身（现无住所，BACKLOG 各段为变更史）：阶段闸门三道（tsc -b 零错 / jest 改动域口径 --no-cache --runInBand / eslint 改动文件 --no-fix 零 error）+ 前端 vite build + 改动域→套件映射由施工总案当批声明。专属闸（触发即加挂）：依赖变更→npm ls invalid=0+npm ci --dry-run；迁移/schema 变更→migration:show 附卷+方言核对；.env 变更→键对账 diff 附卷；新增页面/部署物→部署清单对账行附卷。
- G4 原文：闸门类治本的落地=流程件正文+执行面（命令或自动化）+账本行三处可指认，仅账面宣称=未落地。
- 依据实害：lint 债 335 错（闸门缺 lint 道）；Dockerfile 漏拷 5 页（部署物无闸）；census env 死键 10/未文档 171（env 无对账闸）；案 1 治本仅账面未进总案闸门行（当场已修一处）。

**案2【A2+G2 合并】"入账有期"定义**
- 原文："有期"=①已排期批名+计划文档锚 ②日期 ③可判定触发事件，三选一写入挂账行并带"为什么不做"；三者皆无=问①未过。每逢阶段性验收，过期未触发项须重定期或升级裁决，禁止静默续挂。
- 依据实害：启动瘦身刀挂"归 W-1刀2 或独立小刀"（锚批错位且未开工）；profile-manager 裸 parse 挂 4 天无触发线；抽样 10 挂账中 4 条锚无效。

**案3【A3+G1 合并】同类面边界 + 扫描谓词留痕**
- 原文："同类面"按病根签名划定：同根因+同构形状（可 grep 枚举）的全部出现点，辖域=全仓；发现义务全域（扫不到=没扫）；修改义务限于本次动机面——超动机面的修法=新动机另立批/刀/挂账。扫描谓词必须按病根机制定义并留痕（谓词写法+命中总数+本批处置数+余量去向，入 commit 或账）；按语法形态圈面而病根按机制成立时=问②未过。
- 依据实害：枚举归一批只圈 payment 漏 OrderStatus/UserRole；消声器按语法谓词（spyOn(console）扫，漏同文件 2 处直接赋值式（console.error = jest.fn()）+jest.setup.cjs 1 处注释陷阱。

**案4【A4】治标/治本 × diff 总闸桥接**
- 原文：治标与治本=两个动机：同 commit 者按总闸动机分块（止血块/病根块各自映射），或拆两 commit。禁止以"同一病因"为由混写单动机。
- 依据：宪法 §二总闸已许动机分块，charter 未桥接，一线 agent 可能混写。

**案5【A5】两问①的否定答案出口**
- 原文：①的合法答案含"单例无立法面"：本次诱因唯一、无同构复发面、立闸即违判据 5"单例不立法"——裁明并只记观察，①过关。
- 依据：现行文本把治本形状唯一化为"闸门/模式/约定补进流程"，对单次诱因的病会推向为单例立闸，顶撞同条"单例不立法"。

**案6【A6】复现命令入仓 / 过程证据仓外**
- 原文：承重数字的复现命令必须随卷宗文本入仓（命令级入仓）；过程性证据（截图/中间产物/原卷）仓外+离场自清。"复现命令在各席原卷"不满足本条。溯及：census §三命令未入仓，建议补录。
- 依据实害：census 计数（203 catch/112 裸 Error 等）复现命令实际无处可查——按"无锚数字作废"字面执行会把普查表作废。

**案7【A7】safety.md 事实修正 + 接线批必查条款**
- 原文：:17 行"不接线由 app.module.ts 结构保证（PaymentModule 无 import）"改为现行事实（已挂载）；接线类批验收清单加"触及模块挂载状态者必查 safety.md 对应行"。
- 依据实害：safety.md 是后端工程纪律委托承载体，现含事实错误。

**案8【A8】charter 修订程序**
- 原文：实质修订 commit 必须三同步：版本头、修订史行、commit message 版本号；缺一即违 diff 总闸。触发=判例驱动。
- 依据实害：v1.1/v1.2 两次漏刷版本头（后补登），机制上无防再犯。

**案9【A9+G3 合并】两问日常执行位 + 病根认定权**
- A9 原文：日常档（非里程碑 commit）：施工席在 commit message 动机块尾附两问答案各一行（①答"病根=__/单例无立法面"；②答"同类面=N 处，处置=同批修 M/入账 K/无"）——由 diff 总闸在 message 上查验，不另立闸门。里程碑档仍由审计席设靶执行。
- G3 原文：两问由施工席自答留证；里程碑级交付审计席复核，分歧由协调席复验裁决；非里程碑争议按宪法 §二①-⑥升级。治本判据=可指认流程件——无流程件亦无合格挂账者判治标。
- 依据实害：两问在非里程碑日常施工面上空转（执行主体缺位）。

**案10【A10】双盲审双正身消歧**
- 原文：charter 双盲审节头补辖域声明（本节辖本仓里程碑；workspace 通用规程见 manuals/double-blind-review-charter.md；冲突时本仓里程碑以本节为准）；PRINCIPLES 附录C 指针表补登 manuals 双盲册。
- 依据：两制过审判据不同且互不引用=漂移高危。

**案11【A11】P0-P3 严重度定义**
- 原文：P0=资损/安全/数据破坏级必须立即停线；P1=功能或契约断裂批内必修；P2=记账择期；P3=卫生项。
- 依据：全体系用 P 分级但无一处定义，跨席一致执行不可能。

**案12【A12】呈报模板立件**
- 原文：以 census §六格式为底立空白模板件（问题/选项并列/各席立场栏/无预填），呈报纪律①从描述升为可拷构件。
- 依据：每个会话按描述重新推导（靠纪律不靠构件）。

**案13【G5】两问计数挂钩数字三件套**
- 原文：两问回答中的一切计数按账本数字三件套（复现命令+日期+口径限定语）出口。
- 依据实害：49b62b4"130 例"无命令；d5906bf"43 秒"有工况无命令。
