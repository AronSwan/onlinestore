# 权益保障组三席审查合并裁决书

> 2026-10-06 · 消费者权益保护官/品牌方法务顾问/数据隐私保护官三席 · 协调席合并裁决
> 审查性质：法务/合规/权利视角（全程 20+ 轮审查的缺位维度）；施工双席在途（mid-change 已记录不计分）

## 一、三席判定总览

| 席 | P1 | 核心发现 |
|---|---|---|
| 品牌法务 | 3 | **REICH 商标撞美国 Class 18 在先注册（Reg. #5539651）**；图库图≠卖的货；社会证明虚构+robots index |
| 数据隐私 | 3 | 同意空转（勾选指向不存在的隐私政策）；被遗忘权零机制；密码 console.log 残留 |
| 消费者权益 | 3 | 卖家身份/联系通道全缺（"请联系客服"指向不存在的客服）；社会证明无演示标注；材质规格五处无据 |

**跨席共中（最高置信）**：
- **社会证明种子数据+展示面无标注**：品牌 P1-3+消费者 P1-2 双席共中（+北京心理席早前独立发现）——三源
- **隐私政策不存在但承诺/勾选先行**：隐私 P1①+消费者 P2-1 双席共中
- **图库图 vs 材质规格声明**：品牌 P1-2+消费者 P1-3 双席共中（+北京"图库地雷"）——三源

**三席一致确权的清白面**：授权台账超越商业基准/字体 OFL 二进制层合规/密码 bcrypt 实库验证/鉴权面全绿/退换政策文本超额（30 天+双向运费）/价格零套路（无划线/算术透明/禁用词零命中）/演示边界关键点亮。

## 二、裁决：分三档处置

### A 档：演示期立即修（并入当前施工验收后的修复批，约 0.5-1 人日）
1. **robots 全站 noindex**（品牌 P1-1 防御+P1-3b）——七页 meta 一行
2. **首页可见演示声明**（品牌 P1-3a+消费者 P1-2）——footer 或跑马灯尾"演示项目，数据为示例"八字
3. **隐私政策页成文**（隐私 P1①+消费者 P2-1 双席共中）——privacy.html 五问直答（收什么/存哪/多久/谁看/怎么删——隐私席的数据清单表可直接改写为政策正文）+注册勾选框链活+订阅承诺链同页
4. **密码 console.log 删除**（隐私 P1③）——login-enhanced.js 两行+auth.js 四行调试残留
5. **CREDITS.md 头部边界行**（品牌 P1-2 演示补丁）——"演示商品图文为图库素材，非实际销售商品"
6. **orders meta description 修正**（消费者 P3-1）——"下载发票，管理退换货，有问必答"→"查看订单历史与详情"
7. **PDP 色差提示行**（消费者 P3-3）——"影棚灯光与调色可能造成轻微色差"

### B 档：演示期低成本补（与 A 档同批或下批，约 1-1.5 人日）
8. **卖家身份占位块**（消费者 P1-1）——footer"经营者信息"块（主体占位+可回信邮箱占位+ICP 备案号占位"上线后回填"）；returns.html 客服邮箱占位同款——退货指引两条死链有挂靠点
9. **社会证明演示标注**（双席共中）——数字旁小字"示例数据"（与订单页黄牌同口径）；**不归零**（零值态虽优雅但杀死演示 Showcase，标注方案保两头）
10. **DELETE /api/users/me + profile 注销入口**（隐私 P1②）——本人令牌鉴权+级联清理（users/cart/orders/audit userName）；隐私官的 4 个测试账号随修随清
11. **双份令牌清理**（隐私 P2④）——登录成功清另一存储；refreshToken httpOnly cookie 启用（users_session 表已备）挂下批
12. **包型词口径成文**（品牌 P3-3）——voice-sheet 术语表加一行："行业通用名可用（波士顿/托特/水桶）；设计师命名禁入（凯莉/戴妃）"
13. **gucci 痕迹清理**（品牌 P3-1）——文件改名 user-icon.svg+三处选择器+两处注释

### C 档：商业化硬前置清单（进 BACKLOG 上线 checklist，不修只记账）
- **商标 Clearance**（品牌 P1-1——"每多运营一个月换名成本翻一倍"；检索前不注册域名/不投放/不印吊牌）
- 六图换实拍+规格证据链（材质检测凭证/尺寸实测/工艺供应链核对）
- 社会证明清零重启（代码已支持）+ICP 备案+亮照+TLS 强制
- 审计认证事件接线+保留期限+userName 脱邮箱化（隐私 P2⑤⑦）
- casdoor 探测缓存+第三方披露（隐私 P2⑥）
- 工艺声明供应链核对+AI 资产人工再创作定稿（品牌 P2-2）
- dist 许可伴随文件（品牌 P3-2）

## 三、执行安排

A+B 档并入当前流水线：施工双席交卷 → 大师批双盲审验收 → **权益修复批（A+B 共 13 项一席施工）** → 权益组验收（精简一席）→ 全线收官。C 档写入 BACKLOG 上线硬前置区（与总验收的上线清单合并去重）。
