# Reich 文案定调表（P8a · 前置于 P2）

## 三个定调形容词

**明亮** · **俏皮** · **从容**

- 明亮：不暗调、不emo、不深沉；色彩和语气都向着光。
- 俏皮：像聪明朋友之间的玩笑——有分寸、有双关、没废话。
- 从容：不催促、不尖叫、不"限时抢购"；自信到不需要感叹号。

## 五句示例

1. 首页 hero 引导语：「总有一只先背。——2025 秋冬，到货了」
2. 商品区标题：「IT'S TOTE SEASON · 包包们的季节到了」
3. 订阅区引导：「偶尔来信，不打扰。（真的偶尔。）」
4. 空购物袋：「袋子还空着哦——去看看新朋友？」
5. 愿景横幅：「Reich。慢慢挑，不着急。」

## 禁用词表

| 禁用 | 原因 | 替代 |
|---|---|---|
| 限时 / 抢购 / 秒杀 / 特惠 | 促销语言，与"从容"冲突 | 本季 / 新到 / 心头好 |
| 顶级 / 奢华享受 / 尊贵 | 自封品质=心虚；"大气"靠排版与留白传达 | 不写——删掉让产品说话 |
| 立即 / 马上 / 赶快 | 催促焦虑 | 来看看 / 慢慢挑 |
| ！！！ / 多个感叹号 | 尖叫感 | 句号或省略号 |
| 亲 / 宝 / 宝贝 | 电商客服腔 | 你（或不用称呼） |
| emoji 做正文 | 红线 4：仅营销标题 ≤2 | 文字本身要有趣 |
