## 一、专家组内部分歧终裁（两处）

**1. fly-to-cart 时长公式**：规划席 `clamp(240, d/1.6, 400)` vs 分析席 `clamp(300, d/1.8, 460)`。
**裁**：取规划席 **`clamp(240ms, d/1.6px/ms, 400ms)`、`--dur-flight: 0.4s`**——罗马"≤400ms 别抢 toast 注目"是买手轮已立的硬红线，分析席 460 上限越线；其下限 300 更保守但米兰短距爽快诉求取 240 地板。**采纳分析席重要补强：徽章脉冲从 onfinish 解耦为 itemAdded 即刻触发**（反馈延迟归零，长距飞行是锦上添花而非反馈本体）。

**2. 社会证明口径**：规划席"featured 卡双数" vs 分析席"分位置双口径"。
**裁**：合璧——**featured 主打卡双数**（"N 人的心头好 · M 只已去新家"，主打款社会证明最值钱且卡够大）；**普通卡不挂**（空间紧，只有品质行）；**PDP 信任区双数**（"已去新家 N · M 人收藏"——付款时刻回答"真有人买吗"）。治理三条照分析席：实时读 API **禁硬编码**（数字过期=说谎=本批诚实主题自反）/措辞过禁用词表/**零值态**（favorites=0 显示"来做第一个心动的人"，不显示"0 人"反社会证明）/views 不上（最弱信号，小店大浏览数反读冷清）。
